Migration

The markup half is a command

The codemod's mapping table is not a transcription of the guide — it is the table the visual gate runs against all 292 screenshots. Every entry has been checked by rendering a real page with it and finding that nothing moved.

It is dry by default, idempotent, and refuses to touch a class list it cannot read statically — clsx(...), :class, class:name are reported with a line number, never rewritten.

How it was built

Seven stages, each gated by the one before

The order is the point: nothing was rewritten until there was a way to prove the rewrite had not changed anything.

00 Baselines

292 screenshots of the original, three viewports, approved before a line changed.

01 Tokens

201 DTCG tokens. Ten skins became token overlays instead of ten stylesheets.

02 Stylesheet

Logical properties, container queries, zero !important. Cascade layers were measured and rejected — they lost 58 declarations to a Bootstrap page.

03 Headless core

A pure state machine and one DOM binder. Every listener on an AbortController, proven with heap snapshots.

04 Adapters

Five bindings, none over 2.1 kB, none containing navigation logic.

05 Presets

56 catalogue variants collapsed to 28 presets of 179 B. One render plan; 392 comparisons prove all five adapters emit identical DOM.

06 Scroll-spy & theming

Ninety lines of easing replaced by two CSS properties, and the browser's own focus and history handling.
